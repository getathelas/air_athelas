Scheduling Templates let practices customize a provider's weekly schedule — the hours they work, and what appointments can be booked in each part of the day — and apply that schedule across a defined date range in an easy and simple fashion. Rather than adding individual blocks one at a time, a scheduling manager can build an entire week in a straightforward visual editor, save it as a named template, and apply it to one or many providers.

## Key concepts

Four pieces make up the feature:

| **Term**                 | **What it is**                                                                                                                                                                                    |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Scheduling Template**  | A reusable weekly pattern. It holds a title and optional description, the facilities it applies to, an optional list of providers, and a set of slots.                                             |
| **My Availability**      | The provider's working hours for each day of the week, per facility. This is the outer boundary of the schedule — every slot must sit inside it.                                                   |
| **Slots**                | The individual blocks inside the week. A **bookable** slot renders on the calendar as an open slot and defines which appointment types can be booked in it. A **non-bookable** slot renders as a block and holds time for non-appointments such as lunch, admin time, or meetings. |
| **Template Application** | The step that turns a template into a real calendar. You pick the template, the providers, and a date range, and the system stamps that schedule onto the calendar.                                |

## Creating a template

1. From **EHR Preferences → Calendar → Scheduling Templates**, click “**\+ Provider Schedule**”. The Template Editor opens with a Sunday–Saturday week grid and a configuration panel on the right.
2. Enter a **title** for the template. Give it a name your team will recognize later — "Main Office - Summer Schedule," "PTA Standard Week," "Holiday Coverage."
3. Select the **facility or facilities** and, optionally, the **providers** this template is intended for.
   - _Providers set here are prefilled automatically when you apply the template._
4. Set **My Availability** — the start and end time for each day the provider works. The grid intervals update to match your site and facility calendar settings once availability is entered.
5. Add slots by dragging on the week grid. Click any slot to configure it in the side panel:
   - **Title** (required)
   - **Bookable or non-bookable**
   - **Start and end time**
   - **Days** — If this slot repeats over multiple days of the week
   - **Facilities** — when using multiple facilities, choose which ones this block applies to
   - **Color** — how the block appears on the calendar
   - **Expire if vacant?** — releases the slot's restrictions a set number of hours before the appointment time, so unfilled protected slots can be used
   - **Required Appointment Types** — which appointment types can be booked in this slot
   - **Notes** — optional details for your team, on either bookable or non-bookable blocks
   - **Required Insurance Group** — for bookable slots, select insurance companies or claim insurance types that can use the slot
7. Refine the week with drag-and-drop, resize, and copy/paste. To delete a slot, select it and click **Remove Block**.
8. Click **Save** in the top-right to add the template to your list for reuse, or click **Apply** to put the schedule on a provider’s calendar directly from the builder. You do not have to save it first. Use the back arrow next to the template title to return to the list.

## Building a template with the AI Builder

Rather than placing every slot by hand, you can describe the schedule in plain language and let the assistant build it.

1. In the template editor, switch the right panel from the **Manual** tab to the **AI Builder** tab.
2. Describe the schedule you want in the **Ask Athelas** box. For example: "Create a Monday–Friday schedule 9AM–5PM with a 30-minute lunch break and 40-minute appointment slots."
3. The assistant asks clarifying questions if it needs more detail, then proposes a set of changes and overlays a preview on the week grid.
4. Review the proposed changes. Accept or reject each one individually, or use **Accept All** or **Reject All**. Accepted changes are merged into your unsaved draft.
5. Click **Save** to persist the template.

The assistant can also start from an existing template — for example, "Start with the Summer Schedule but begin at 9AM" — and can build common patterns such as alternating single- and double-book cycles, or payer-differentiated slot lengths.

### **Applying Directly from the Builder**

For a short-term change — a holiday week, a few days of coverage, or a different set of hours — you can build the schedule and apply it without adding another template to your list.

1. Create a schedule in the Template Editor, or open an existing template and make your changes. You can use either **Manual** or **AI Builder**.
2. Click **Apply** next to **Save** in the top-right. This uses the schedule currently shown in the builder, including unsaved changes.
3. Confirm the **providers**, **Start Date**, and optional **End Date**, then click **Apply Schedule**.
4. If existing templates overlap your dates, review which ones to **Keep** or **Replace** (see **Keeping Existing Templates When Applying a New Schedule**).
5. Review the confirmation and any conflict counts, then click **Apply Schedule** to finish.

Your changes stay in the builder afterward, so you can keep editing, apply them to another provider, or click **Save** to keep the template for reuse.

<Note>
  **Note:** **Save and Apply do different things.** Apply updates the selected providers’ calendars. It does not add a new template to your saved list or update the saved template you started from. Save keeps your changes in the template list, but does not update calendars that already have a schedule applied.
</Note>

### **Starting from an Existing Schedule**

You can also use another saved schedule as your starting point without leaving the builder.

1. In the **Manual** panel, click **Copy from an existing schedule**.
2. Select a schedule and review its facilities, availability, and blocks.
3. Click **Apply schedule**, or **Replace schedule** if your draft already has hours or blocks.

This replaces the facilities, availability, and blocks in your draft while keeping its title, description, and providers. It does not change a provider’s calendar. Review the copied schedule, then **Save** or **Apply** it when you are ready.

### **Applying a Template to a Provider’s Calendar**

Saving a template does not change anyone's calendar. Only applying the template will update what displays on a provider’s calendar. To do this:

1. Open the **Scheduling Templates** drawer from the calendar toolbar, or navigate to the template in EHR Preferences.
2. Select the template and click **Apply**. The **Apply Schedule Template** modal opens.
3. Confirm the **providers**. Any providers set on the template are prefilled; you can add or remove them here.
4. Set the **Start Date**. To bound the schedule, turn on **Have schedule expire on specific date** and set an **End Date**. Leave it off for an open-ended schedule.
5. Click **Apply Schedule** to review the application. If the **Overlapping schedules** step appears, choose which existing templates to **Keep** or **Replace**, then click **Continue**.
6. Review the confirmation message and any conflict counts. Click **Apply Schedule** to finish, or, when applying from the calendar with conflicts, choose **Apply Only** or **Apply & View Conflicts**.

<Warning>
  Only one template can be in effect per provider on a given day. Applying a template over a date range updates **template-generated schedule coverage** for the dates you select, except for existing schedules you choose to **Keep**. It does not always remove the provider's entire calendar history.

  How existing template coverage is resolved depends on overlap:

  - **Fully inside the new range:** the prior applied schedule is removed for that period.
  - **Starts before the new range and ends inside it:** the prior schedule is **shortened** so it ends the day before the new start date.
  - **Starts inside the new range and extends past the new end date:** the prior schedule is **shortened** so it resumes the day after the new end date.
  - **The new range falls in the middle of an existing schedule:** the existing schedule is **split**. The portion before the new range stays, the portion after resumes after the new range ends, and the middle is replaced by the newly applied template.
</Warning>

### **Keeping Existing Templates When Applying a New Schedule**

When changing a provider’s regular schedule, you may want to keep a holiday or out-of-office template that is already on the calendar. Where this option is enabled, the **Overlapping schedules** step lets you make that choice before applying.

1. Select your providers and dates, then click **Apply Schedule**.
2. Review the overlapping templates. Each row shows the template name and the providers and dates it covers. Hover over **+N more**, if shown, to see additional schedules.
3. Choose an action for each template:
   - **Keep** — leaves that template on the calendar. The new schedule applies around its dates.
   - **Replace** — replaces that template within the date range you are applying. This is the default.
4. Click **Continue**. The confirmation shows which templates will be replaced, which will be kept, and any appointment or slot conflicts in the dates being changed.
5. Confirm the application. You can use **Back** to change your choices before applying.

For example, if you are applying a new regular schedule from November onward, choose **Keep** for “Thanksgiving OOO” and “Christmas OOO.” The new schedule fills the dates around those breaks.

### **What happens to recurring template slots**

Template-generated **recurring** slots (for example, weekly appointment slots) follow the same date range you apply. When a new apply overlaps an existing recurring series:

- Occurrences **inside** the apply range are replaced by the new template's slots, except where you chose to **Keep** an existing schedule.
- Occurrences **before** the apply range are preserved as a continuing series on the calendar.
- Occurrences **after** the apply range are also preserved. If the underlying applied schedule was split around your date range, the post-range portion stays linked to the surviving schedule after the gap.

In practice, applying a two-week template over a year-long schedule replaces those two weeks only. Recurring slots outside that window remain.

<Info>
  **Manual slots are not removed by apply.** Apply overwrites **template-generated** slots and applied schedule coverage in the selected range. Slots you created directly on the calendar are left unchanged, even if they overlap the apply range. Booked appointments are also unchanged.
</Info>

## Managing templates

From **Preferences → Calendar → Scheduling Templates** you can:

- **Search and filter** the template list by provider and by facility.
- **Duplicate** a template as the starting point for a variation.
- **Edit** a template. Changes affect future applies only, not schedules that have already been applied.
- **Delete** a template using the trash icon in its row.

<Note>
  **Note:** Deleting a template does not remove blocks that have already been placed on a calendar.
</Note>

## The Scheduling Templates drawer

Once a template is applied, it drives what the calendar shows. Open the drawer from the **Scheduling Templates** icon in the top-center of the calendar toolbar. It contains:

- **Visible on Calendar** — a toggle at the top that shows or hides template shading and blocks. Your preference is remembered.
- **Active** — schedules currently in effect, grouped by provider. Expand or collapse a provider’s name to see their applied schedules. The number beside the name is the number of schedule entries in that section. Shows **No templates active** when there are none.
- **Upcoming** — schedules that start in the future, also grouped by provider and ordered by start date. Hidden when empty.
- **Schedule dates** — each row shows the template name and its start and end dates, or **No end date** for an open-ended schedule. The same template can appear more than once when it has been applied for separate periods.
- **Clear** — hover over a schedule row to reveal this action. It opens the clear dialog for that provider and schedule.
- **All Templates** — a collapsible list of saved templates at the site, with search and provider and facility filters.

Active and Upcoming follow today’s date at your site and the providers selected on the calendar. They show what is applied; **All Templates** shows what is saved for reuse. A schedule applied directly from the builder can appear under Active or Upcoming even when you did not save it to the template list.

### **Clearing a Template from a Provider’s Calendar**

Clearing removes a template from providers' calendars over a date range. It can also cancel a template that is scheduled to start in the future. To do this:

1. Open the **Scheduling Templates** drawer from the calendar toolbar.
   - _Clearing is only available from the calendar, not EHR Preferences._
2. Expand the provider under **Active** or **Upcoming**, hover over the schedule row you want to remove, and click **Clear**. The **Clear Template** modal opens, or **Cancel Upcoming Template** for a schedule that has not started yet.
3. Confirm the **provider** shown. Clearing from a row targets that provider’s schedule; it does not select every provider who uses the same template.
4. Set the **Start Date**. To clear a set period, turn on **Have schedule expire on specific date** and set an **End Date**. Leave it off to clear everything from the start date onward.
5. Click **Clear Schedule Template**.

<Info>

Appointments in cleared slots stay booked but may appear as conflicts (see **Resolving Conflicts**). Clearing does not restore the template that was there before. To put a schedule back, apply the desired template again.

### **Resolving Conflicts**

Applying or clearing a template can leave existing appointments and slots out of step with the new schedule. These show up as conflicts. Conflicts never block an apply or clear; you can resolve them afterward.

- **Slot conflicts:** a manual slot falls within the applied or cleared date range.
- **Appointment conflicts:** a booked appointment no longer fits the schedule — for example, there is no available bookable slot, the available slots are already at capacity, or the appointment does not match the slot’s restrictions.

When you apply a template from the calendar, the confirmation step shows the number of conflicting appointments and slots. Click **Apply Only** to apply now, or **Apply & View Conflicts** to apply and open the **Conflicts** tab. When applying from the builder or EHR Preferences, you can return to the calendar to review conflicts afterward.

To resolve conflicts:

1. Click the requests button in the calendar header and open the **Conflicts** tab.
2. Filter by **conflict type**, **provider**, **patient**, or **facility** as needed. The list shows unresolved conflicts from today onward, with the earliest dates first. Scroll to load more.
3. Review each row’s date, time, and details, then choose an action:
   - **Slots** — click **Remove** to remove the manual slot, or open the action dropdown and choose **Keep** to leave it on the schedule and mark the conflict resolved.
   - **Appointments** — click **Reschedule** to open the appointment on the calendar and choose a new time. Use the dropdown to **Keep** it as is, **Cancel**, or **Archive** it. You can also click the patient’s name to open their profile.
4. To resolve several at once, select the rows and use the bulk actions at the top:
   - **Slots only** — **Keep** or **Delete**.
   - **Appointments only** — **Keep** or **Cancel**.
   - **Slots and appointments together** — the action menu lets you keep all, delete the selected slots, or cancel the selected appointments.
5. Review the confirmation before removing slots or canceling appointments.

<Info>
  **Select all only selects the rows already loaded in the list.** Scroll to load more conflicts before selecting additional rows. The **Clear** button in the bulk action bar clears your selection; it does not clear a template from the calendar.
</Info>

Keeping an appointment means you have reviewed it and want it to stay scheduled, even if it does not fit the new template. Rescheduling is complete only after you choose and save a new appointment time.

## Booking appointments on available slots

To book into a bookable slot, click the **+** in the center of the slot.

1. The **New Appointment** modal opens with the **Appointment Type** dropdown suggesting the types the slot allows.
2. The appointment duration defaults to the appointment type's configured duration, not the full length of the slot. If the appointment runs into the next slot and that slot permits the same type, the next slot is consumed as well. Otherwise the remaining time stays open and bookable.

## Overlapping appointment logic

Each appointment type has an **allow overlapping bookings** setting, configured in the appointment type form — see [**Appointment Types**](/air_admin/manage_your_practice/appointment_types). When it is disabled, that appointment type cannot be booked more than once at the same time for a provider, even if multiple slots are open in that window.

Use this together with slot layout: side-by-side slots create the capacity, and the appointment type setting decides whether a given type is allowed to consume more than one of them.

### FAQ

<Accordion title="**How do I keep holiday or out-of-office schedules when changing regular hours?**">
  Where the overlapping schedules step is enabled, choose **Keep** for those templates before confirming the new application. Leave **Replace** selected for the regular schedule you want to change. Review this each time you apply.
</Accordion>

<Accordion title="Does saving a template change any calendars?">
  No. A saved template is only configuration. Nothing appears on a calendar until you apply it to specific providers and dates.
</Accordion>

<Accordion title="What happens to a template I edit after it has been applied?">
  The edit affects future applies only. Schedules already generated from the earlier version stay as they are. To push the change out, re-apply the template to the relevant providers and date range.
</Accordion>

<Accordion title="Can a provider have two templates running at once?">
  No. One template is in effect per provider at any point in time. A newly applied template replaces the coverage for the range you select.
</Accordion>

<Accordion title="Can I still create one-off blocks manually?">
  Yes. Individual slots can still be created and edited directly on the calendar, and a single occurrence of a recurring slot can be changed or removed without affecting the rest of the series.
</Accordion>

<Accordion title="What happens if the feature is turned off for my site?">
  The Scheduling Templates interface is hidden and the calendar returns to legacy [**Reserve Blocks**](/air_front_desk/portal_and_online_scheduling/reserve_blocks) and schedule blocks, with provider hours managed again from [**Provider Settings**](/air_admin/manage_your_practice/provider_settings).
</Accordion>

<Accordion title="**Can I apply a schedule without saving a template?**">
  Yes. Click **Apply** in the builder to use the schedule currently shown, including unsaved changes. It updates the selected providers’ calendars without adding a template to your saved list. If you started from an existing template, that saved template stays as it was until you click **Save**.
</Accordion>
