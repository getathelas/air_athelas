---
title: "How to create tasks"
description: "Create a task on the Tasks page, assign it to a user or a group, and optionally link it to a patient."
---

On the [Tasks](https://insights.athelas.com/tasks) page, click **Task** in the header to open the **Create Task** drawer. Fill in:

- **Title** (required) and a clear **Description**
- **Assignee** — switch between **Assign to an Individual User** (choose an **Assignee**) and **Assign to a Group** (choose an **Assignee Group**). Group-assigned tasks can be claimed by any member of the group.
- **Patients** (optional) — link the task to one or more patients; linked tasks appear on each patient's profile
- **Priority** — No Priority, Low, Medium, High, or Urgent
- **Status** — defaults to **Not Started**
- **Due Date**
- **Task Type** — pick an existing type or manage the list via **Manage Task Types**
- **File** — optionally attach a file (larger files take longer to upload)

Click **Create**.

### FAQ

<Accordion title="Can I assign a task to a team instead of one person?">
  Yes. In the **Assignee** section, choose **Assign to a Group** and select an **Assignee Group**. Any member of that group can claim and work the task.
</Accordion>

<Accordion title="How do I link a task to a patient?">
  Add the patient (or patients) in the **Patients** field when creating the task. The task then appears on that patient's profile.
</Accordion>
