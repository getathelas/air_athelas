## Overview

The **EOBs** tab on the **Remittances** page is where you upload Explanation of Benefits (EOB) files to Insights. It replaces the **EOB Creation** page and its **Post a New EOB** button, which were retired on September 30, 2026.

This guide covers where to find the EOBs tab, how to upload one or several EOBs at once, and what to do if you cannot see the page.

<Info>
  Old bookmarks and saved links to the **EOB Creation** page no longer work. Update them to [https://insights.athelas.com/remittances/eobs](https://insights.athelas.com/remittances/eobs).
</Info>

## Find the EOBs tab

1. In the left navigation menu, open **Daily Operations**.
2. Select **Remittances**.
3. Click the **EOBs** tab at the top of the Remittances page.

You can also go straight to the tab with this link: [https://insights.athelas.com/remittances/eobs](https://insights.athelas.com/remittances/eobs).

If you are on the old **EOB Creation** page, click the **new EOBs page** link in the banner at the top of the page.

## Upload EOBs

### Upload a single EOB

1. Open the **EOBs** tab.
2. Click **Create EOB**.
3. Drag the EOB PDF into **Drop Files Here**, or click **Browse Files** and select the file.
4. Click **Save**.

### Upload multiple EOBs at once

You can upload several EOB files in one go. This is the replacement for bulk upload on the old EOB Creation page.

1. Open the **EOBs** tab.
2. Click **Create EOB**.
3. Drag every EOB PDF into **Drop Files Here**, or click **Browse Files** and select all of the files.
4. Click **Save**.

An **Upload EOBs** panel shows the progress of each file. Each uploaded file appears as a new row on the EOBs tab.

## I can't see the Remittances page or the EOBs tab

Access to the Remittances page, including the EOBs tab, is controlled by the **Remittances** page permission on each user.

| **Role** | **Remittances access by default** |
| :--- | :--- |
| **Administrator** | Yes |
| **Billing Manager** | Yes |
| **Staff** | No |

A user without the **Remittances** permission does not see **Remittances** in the navigation menu, and opening the EOBs link sends that user to the Home page.

<Warning>
  The old **EOB Creation** permission does not carry over. A user who could open the EOB Creation page still needs the **Remittances** permission to reach the EOBs tab.
</Warning>

### Grant access _(administrators)_

1. Go to **Settings → My Practice → Team Members**.
2. Find the user and click the **Edit** icon at the end of the row.
3. Under page permissions, tick **Remittances**.
4. Click **Save**.

The user may need to log out and log back in to see the change.

### FAQ

<Accordion title="Where did the Post a New EOB button go?">
  The **EOB Creation** page and its **Post a New EOB** button were retired on September 30, 2026. Use the **Create EOB** button on the **EOBs** tab instead: **Daily Operations → Remittances → EOBs**.
</Accordion>

<Accordion title="How do I bulk upload EOBs like before?">
  Click **Create EOB** on the **EOBs** tab and select all of the files you want to upload. Multiple EOB files can be uploaded in one go.
</Accordion>

<Accordion title="Why does the EOBs link take me to the Home page?">
  Your user does not have the **Remittances** page permission. Ask an administrator at your practice to enable the permission under **Settings → My Practice → Team Members**, then log out and log back in.
</Accordion>

<Accordion title="I had access to EOB Creation. Why can't I see the new page?">
  The old **EOB Creation** permission does not carry over to the new page. The EOBs tab requires the **Remittances** permission, which is enabled by default for the **Administrator** and **Billing Manager** roles but not for **Staff**.
</Accordion>
