#### Summary

The **Adjustments Report** provides a detailed, line-item journal of every adjustment posted during a period. Each row represents a single adjustment component on a claim — whether it is a contractual write-off from a payer, a custom write-off type (bad debt, sliding fee adjustment, financial assistance, etc.), or a residual other adjustment. This gives your RCM team a full audit trail of where money was written off and why.

<Note>
This is different from the [Claim Adjustments Report](/insights_biller/reports/claim_adjustments_report), which groups adjustments at the payer level per encounter. The Adjustments Report is a line-item journal with one row per adjustment component, including reason codes.
</Note>

#### Key Use Cases

- Audit all adjustments by type and payer for a given posting period.
- Spot-check large write-offs or unusual adjustment activity.
- Reconcile total adjustments against the [Revenue Activity Report](/insights_biller/reports/revenue_activity_report) for the same period.
- Identify which adjustments were posted by Athelas's auto-poster vs. manual staff.

<Tip>
The sum of all **Amount Adjusted** values in this report ties to the total adjustments shown in the Revenue Activity Report for the same site and date range.
</Tip>

#### Data Dictionary

| Column Name | Description |
| --- | --- |
| Date Posted | Date the adjustment was posted in the system. |
| Adjustment Type | Category of the adjustment: "Contractual Adjustment", "Write Off", "Sliding Fee Adjustment", "Write Off PR", or a custom code from the write-off type catalog (e.g. BD = bad debt, SFS = sliding fee). |
| Patient Name | Full name of the patient on the claim. |
| Facility | Name of the facility where the encounter took place (blank if no facility is set on the encounter). |
| Rendering Provider | Full name of the rendering provider on the encounter (blank if none is set). |
| Payer Name | Insurance payer name as submitted on the claim; "SELF-PAY" for patient responsibility adjustments. |
| Adjustment Reason Code | CARC (for contractual) or OARC (for other adjustments) codes explaining why the adjustment was applied. |
| Payer Index | Which payer in the coordination of benefits chain the adjustment applies to (1 = primary, 2 = secondary, 3 = tertiary, 4 = patient). |
| Claim Submission ID | Insights identifier for the specific claim submission this adjustment is tied to. |
| Payer Group | Financial class or payer grouping (e.g. Medicare, Medicaid, Commercial). |
| Description | Free-text description of the adjustment (from the write-off type catalog or posting notes). |
| Amount Adjusted | Dollar amount of the adjustment (positive = money written off). |
| User | Person who posted the adjustment; displayed as "Athelas" for rows created by the auto-poster. |

#### Filters Supported

- Date Range — filter by Date Posted
