The Attachments tab will house all the attachments related to the patient. Any intake form will automatically be sent here, along with any uploaded scripts from the chart note.

<img src="/images/insights_provider/patient_profiles/add_attachments_to_patient_profile/add_attachments_to_patient_profile_1.png" alt="Attachments tab in a patient profile" />

You will also be able to add, filter and search attachments within this tab.

<img src="/images/insights_provider/patient_profiles/add_attachments_to_patient_profile/add_attachments_to_patient_profile_2.png" alt="Patient attachment search and filtering controls" />

### Upload attachments

**Before you start:** Open the patient profile and select **Attachments**.

1. Select **Add** to open the **Add Attachments** drawer.
2. Choose one or more files and add any tags.
3. For a single file, update **Attachment name** if needed. The file extension remains unchanged. This field does not appear when you upload multiple files.
4. Confirm **Document date**, which defaults to today, or clear it.
5. Complete the upload.

<img src="/images/insights_provider/patient_profiles/add_attachments_to_patient_profile/add_attachments_to_patient_profile_3.png" alt="Add Attachments drawer with file details" />

<img src="/images/insights_provider/patient_profiles/add_attachments_to_patient_profile/add_attachments_to_patient_profile_4.png" alt="Attachment upload and tag controls" />

When an attachment is uploaded, select it to view the available actions.

<img src="/images/insights_provider/patient_profiles/add_attachments_to_patient_profile/add_attachments_to_patient_profile_5.png" alt="Actions available for an uploaded attachment" />

You can download the file or send it by email, text, or fax.

<img src="/images/insights_provider/patient_profiles/add_attachments_to_patient_profile/add_attachments_to_patient_profile_6.png" alt="Attachment download and send options" />

<img src="/images/insights_provider/patient_profiles/add_attachments_to_patient_profile/add_attachments_to_patient_profile_7.png" alt="Attachment delivery options" />

### FAQ

<Accordion title="Can I rename files when uploading several attachments?">
No. **Attachment name** appears only for a single-file upload.
</Accordion>

<Accordion title="What happens if the document date cannot be saved?">
The attachment can still upload successfully. A message tells you that the file uploaded but its document date could not be saved.
</Accordion>
