Access, filter, and manage patient documents such as faxes, images, and other uploaded files.

**Before you start:** Open the patient profile and select **Attachments**.

## Upload attachments

1. Select **Add** to open the **Add Attachments** drawer.
2. Choose one or more files.
3. For a single file, update **Attachment name** if needed. The file extension remains unchanged. This field does not appear when you upload multiple files.
4. Confirm **Document date**, which defaults to today, or clear it.
5. Complete the upload.

## Find and open attachments

- Search for documents using the search bar, or filter by document type. For example, filter by **Faxed** documents.

![Attachments search and document type filters](/images/air_provider/review_patient_details/patient_attachments/patient_attachments_1.gif)

You can then:

- **Download** files by selecting the checkbox and clicking **Download** to the right of the search box.
- **View** a file by clicking the black eye icon to the right of the selected file.

![Attachment preview control in a patient profile](/images/air_provider/review_patient_details/patient_attachments/patient_attachments_1.webp)

### FAQ

<Accordion title="Can I rename every file in a multi-file upload?">
No. **Attachment name** is available only when you upload one file at a time.
</Accordion>

<Accordion title="What happens if the document date cannot be saved?">
The file upload can still finish. A message tells you that the attachment uploaded but the document date could not be saved.
</Accordion>
