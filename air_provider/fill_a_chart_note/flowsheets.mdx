Flowsheets v2 improves documentation efficiency and aligns PT documentation with billing practices. The system is **CPT-centric** — billing codes are set up first with interventions nested underneath, reducing clicks and making documentation cleaner and faster.

The system auto-calculates units from minutes, supports manual adjustments, can carry forward interventions from previous visits, and lets you optionally mark exercises for Home Exercise Programs (HEP).

More details: [Flowsheets v2 User Guide](https://athelas-public.notion.site/Flowsheets-v2-User-Guide-357f92a633f280bc8767c1a40fb79503)

![Flowsheets overview](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_1.webp)

## Adding procedure codes

Creating CPT blocks in Flowsheets begins by adding a CPT code. The CPT-centric structure mirrors actual billing practices, making documentation faster and more aligned with provider workflows.

1. **Click the "+ CPT" button** at the top of the flowsheet.
2. **Search for a CPT code** by number (e.g., `97110`) or by description (e.g., "therapeutic exercise"). Select the code from the dropdown.
3. **Fill in the CPT block** — modifiers, minutes, provider, and status.

   ![CPT block fields after selecting a procedure code](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_2.webp)

Minutes are entered **once per CPT block**, avoiding repetition for each intervention. Units are auto-calculated from the minutes at the CPT block level — manual adjustments can be made if needed.

## Tracking interventions

Once you have a CPT block, interventions can be added underneath it. Use either free text or the library, and both methods can be combined freely.

### Free text

1. **Click "+ Add Intervention"** under the CPT block.
2. **Type the intervention name directly** (e.g., "Hip abduction", "TheraBand rows").
3. **Press Enter or Tab** to confirm.

Free text lets you add interventions without searching the library when you already know what you want to write.

### Library search

1. **Click "+ Add Intervention"** under the CPT block.
2. **Type `/`** to open the library search.
3. **Search by exercise name** and select from the results to add a structured intervention with pre-filled parameters.

   ![Library search results under the intervention field](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_3.webp)

### Intervention groups

1. **Click "+ Add Intervention"** under the CPT block.
2. **Switch to the "Intervention Groups" tab.**
3. **Search by group name** and select to add a structured intervention with pre-filled parameters.

   ![Intervention Groups tab](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_4.webp)

## Managing interventions

### Marking interventions done

Click the checkmark on any individual intervention to mark it complete, or use the Summary Bar's **Mark All Done** button to complete the entire flowsheet in one click.

<Note>
  **Mark All Done** does **not** trigger any billing actions. Marking interventions as done improves documentation and supports PDF generation after submission — it has no impact on what is billed. Billing is based on the procedure codes entered on the flowsheet, along with their associated minutes and units.
</Note>

### Reordering interventions

Interventions can be reordered within a CPT block by dragging and dropping. They can also be moved between CPT blocks if they need to be reassigned to different billing codes.

![Drag handle for reordering interventions](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_5.webp)

### Concurrent interventions

When two interventions are performed simultaneously — for example, an exercise done while receiving e-stim — use the concurrent interventions feature to accurately represent overlapping time.

![Marking two interventions as concurrent](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_6.webp)

### Deleting interventions or CPT blocks

You can remove individual interventions or entire CPT blocks using the menu options. **Deleting a CPT block also removes every intervention nested under it.**

![Menu option to delete a CPT block](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_7.webp)

## Information carry-forward

Have a patient who does roughly the same exercises each visit? Carry Forward pulls interventions from a previous visit into the current one, saving you from rebuilding the flowsheet from scratch every time.

Carry forward happens automatically for flowsheets:

| Note type     | Pulled from         | Gates / rules                                                                       |
| ------------- | ------------------- | ----------------------------------------------------------------------------------- |
| Initial eval  | N/A                 | No carry forward (first note in case).                                              |
| Daily note    | Latest note in case | Interventions, CPT codes, and details; must be from another Flowsheets v2 visit note. |
| Progress note | Latest note in case | Same as daily.                                                                      |

## Creating and managing Home Exercise Programs (HEPs)

### Creating HEPs

Toggle the **HEP** option to mark exercises the patient will perform at home. This option is optional and should only be used for exercises intended for home practice.

![HEP toggle on an intervention](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_8.webp)

### Sending the HEP email

When you're done with the flowsheet, you can generate a PDF summary and send a Home Exercise Program email to the patient.

1. **Click "Send HEP Email"** to email the patient their Home Exercise Program.
2. **Only interventions marked as HEP** are included.
3. **Confirm the patient's email address or phone number** before sending.

![Send HEP Email dialog with patient contact confirmation](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_9.webp)

## Flowsheets add-ons

### Summary bar

The Summary Bar appears at the bottom (or top) of your flowsheet and gives a real-time overview of the entire visit:

- **Total treatment time** — sum of all minutes across all CPT blocks.
- **Total units** — sum of all auto-calculated units across all CPT blocks.
- **Completion status** — how many interventions are marked done vs. total.

The **Mark All Done** button in the Summary Bar marks every intervention across the entire flowsheet as complete in a single click — perfect for end-of-visit wrap-up. You can also toggle from automatic to manual unit calculation from the Summary Bar.

![Summary Bar with totals and Mark All Done](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_10.webp)

### Comments

The Flowsheet Comments section lets you add rich text notes to the visit — clinical observations, patient feedback, session highlights, or anything else relevant that doesn't fit into structured fields.

- Click the **Comments** area to open the rich text editor.
- Format text with bold, italic, bullet lists, and more.
- Comments are saved with the flowsheet and visible in the visit record.

![Flowsheet Comments rich text editor](/images/air_provider/fill_a_chart_note/flowsheets/flowsheets_11.webp)

### Time in clinic

Track the patient's actual time in the clinic separately from treatment time using the **Time in Clinic** fields.

- **Time In** — when the patient arrived and treatment began.
- **Time Out** — when the patient's visit ended.

These fields auto-populate with the appointment start and end times, but can be manually adjusted.

### Keyboard shortcuts

- **Tab** — navigate between fields (move from minutes to modifier to provider, etc.).
- **Shift + Tab** — navigate backwards between fields.
- **`/` (forward slash)** — while in the intervention field, opens library search.
- **Enter** — confirm a free text intervention or library selection, or "click".

### Power user tips

- Use multi-select CPT codes to **bulk Add CPT** to set up all your billing codes for the visit in one shot before adding any interventions.
- **Tab through CPT block fields** quickly — you rarely need to click.
- For routine patients, **review what carry forward populated**, then just update the minutes and any changed exercises.
- **Only use `/` library search** when you need structured parameters or are building a HEP — otherwise just type the name directly.
- Use the Summary Bar's **Mark All Done** at the end of the visit to quickly close out all interventions.
- If using scribe, **speak in clinical shorthand** — the scribe understands codes, minutes, and exercise names.
