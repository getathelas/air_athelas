## Setup & Admin

| Capability | What it is |
| :-- | :-- |
| **Staff & permission management (RBAC)** | Roles with page- and action-level permission gates, scoped by site or facility. |
| **Practice settings** | Locations, hours, and facilities. |
| **Provider credentialing** | Payer enrollment and credentialing status per provider, in one place. |
| **Provider settings & e-Rx registration** | Provider configuration and Surescripts enrollment. |
| **Appointment type & calendar setup** | Appointment types, templates, and provider hours. |
| **Athelas Assistant** | AI copilot that answers plain-English questions about your live billing data. |
| **EDI & ERA enrollments** | Every provider registered with every payer, handled by Athelas at onboarding. |
| **Stripe account & POS setup** | Athelas sets up your Stripe account and gets card readers live. |
| **Coaching & training** | One-time onboarding and training during launch. |

## Rules & Submission

| Capability | What it is |
| :-- | :-- |
| **Billing rules** | View, toggle, and prioritize rules, and author modifier and coding logic. |
| **Claim transformation & blocking rules** | Scrub, split, hold, or block claims. |
| **Draft → promote workflow** | New rules stay inactive until you deliberately activate them. |
| **AI rule generation** | Describe a rule in plain language and get a working draft. |
| **Impact preview** | See which claims and appointments a rule would touch before launch. |
| **Rule audit trail & rollback** | Every version kept, with one-click restore. |
| **Plain-language rule view** | A human-readable summary next to each rule, with internal IDs resolved. |
| **Claim activity timeline** | Who or what changed the claim, and when. |
| **Full dry-run (historical replay)** | Before-and-after diff of a rule against past claims. |
| **Phased rollout cap** | New rules apply to a sample of claims first, then expand. |
| **Per-encounter block override** | Override a block on one encounter, with documented justification. |
| **AI Filters** | Describe the view you want and let AI sort, group, and filter. |
| **Claim pre-flight review** | Build and validate a claim without sending it. |
| **Electronic claim submission** | Validated, verified, then transmitted on the right route per payer. |
| **Claims workspace** | One unified worklist for rejections, denials, and claim details. |
| **Bulk actions** | Multi-select claims and act at scale with 20+ bulk actions. |
| **Defer claims** | Defer with a reason, to capture work done outside Insights. |
| **Corrected-claim resubmission** | Proper correction coding, in bulk, duplicate-guarded. |
| **Claim notes** | Comments on claims, single or bulk. |
| **Records & attachments with claims** | Send supporting records by fax, email, mail, or electronically. |
| **Athelas Assistant across a claim selection** | Ask anything and act across one claim or every claim you selected. |
| **Unified claim context** | Submissions, remittances, payments, and attachments side by side. |
| **Drug code (NDC) auto-resolution** | Correct NDC, units, and drug details filled in automatically on drug claims. |
| **Managed EHR extraction** | Scheduled pull of appointments, encounters, charges, and records from your existing EHR. |
| **Eligibility-enriched submission** | Claims enriched with fresh eligibility before they go out. |
| **Create a claim manually** | Build a claim from scratch, with the same rules gate as any other. |
| **Payer claim status** | Payer-reported status on the claim and its timeline. |
| **Claim voids** | Void a claim in product, with proper payer void coding. |
| **One-click eligibility from the claim** | Run eligibility against any insurance on the claim. |

## A/R & Denials

| Capability | What it is |
| :-- | :-- |
| **Automatic 835 intake** | Remittances pull from every clearinghouse, with codes translated to plain English. |
| **AI EOB transcription** | Scanned EOBs extracted line by line and confirmed against the image. |
| **Posting review tool** | Dry-run any posting action, then commit. |
| **Adjustment code management** | Standard adjustment codes, viewable and mappable per site. |
| **Denial worklist** | Denials grouped by reason, payer, and type, with dollars at risk per bucket. |
| **Denial categorization** | Plain-English CARC and RARC views, with worked and recovered-revenue KPIs. |
| **Bulk denial actions** | Assign, tag, defer, and resubmit denials at scale. |
| **Appeal supporting docs** | Attach records to any claim, any time. |
| **EOB creation & payer-portal checks** | Manual remittance intake for anything that never arrives as an 835. |
| **Bulk EDI (835) download** | Download raw 835 files in bulk for external accounting or posting systems. |
| **Zero-touch posting** | Balanced remittances post with no manual touch; only exceptions are held. |
| **Contractual adjustments (ARES)** | Automatic write-offs, tagged regrettable or expected. |
| **Appeals** | AI-drafted appeal letters, packet assembled and filed on the payer's channel. |
| **Appeal status & history** | Per-claim appeal status, interleaved with full submission history. |
| **A/R aging** | Bucket to payer to patient to claim, exportable as CSV or PDF. |
| **KPI dashboards** | First-pass rate, collection rate, days to paid, and provider productivity. |
| **Metric drill-down** | Every number opens to the claims behind it. |
| **Payer mix & performance** | Your whole book of business, broken down by payer. |
| **Report templates** | Roughly 20 configurable templates plus saved views. |
| **AI report builder** | Ask a plain-English question and get a live report you can save. |
